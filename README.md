# Tanvir Hasan Portfolio

A responsive single-page portfolio inspired by the supplied reference design.

## Run locally
Open `index.html` in a browser.

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save.

## Customize
- Replace the placeholder portrait in `style.css` with your real photo if desired.
- Update project links, social links, email, education, experience, and certificates in `index.html`.
